# 🎓 UniSchedule (برنامه‌ریز انتخاب واحد دانشگاه)

یک ابزار مدرن، متن‌باز و کاملاً سمت کاربر (Client-Side) برای کمک به دانشجویان جهت برنامه‌ریزی انتخاب واحد و مدیریت جدول زمانی کلاس‌ها و امتحانات.

## ✨ قابلیت‌ها (Features)

- **گرافیک و رابط کاربری مدرن:** طراحی شده با اصول روز UI/UX، دارای پشتیبانی کامل از دارک‌مود و طراحی کاملا ریسپانسیو (Responsive).
- **وارد کردن خودکار دروس (از سیستم بهستان):** امکان Import کدهای HTML گزارش ۲۱۲ بهستان برای تولید خودکار دیتابیس دروس بدون نیاز به وارد کردن دستی.
- **تشخیص هوشمند تداخلات:**
  - تشخیص تداخل زمانی کلاس‌ها.
  - تشخیص هم‌پوشانی تاریخ و ساعت امتحانات پایان‌ترم.
- **برنامه‌ریزی چندگانه (Multi-Plan):** امکان ایجاد تب‌ها و پلن‌های مختلف (مثلاً پلن الف، پلن ب) و مقایسه آن‌ها با هم.
- **تقویم امتحانات یکپارچه:** یک نمای گرافیکی تمیز برای مرتب‌سازی و نمایش زمان‌بندی امتحانات پایان‌ترم بر اساس تاریخ برگزاری.
- **خروجی چاپ (Print-Friendly):** بهینه‌سازی کامل صفحات جهت پرینت گرفتن از برنامه هفتگی و تقویم امتحانات در قالب PDF.

## 🚀 تکنولوژی‌های استفاده شده

این پروژه با رویکرد توسعه مدرن وب (Modern Web Development) نوشته شده است:
- [React](https://reactjs.org/) (کامپوننت‌های تعاملی)
- [TypeScript](https://www.typescriptlang.org/) (برنامه‌نویسی تایپ‌سیف و قابل اطمینان)
- [Vite](https://vitejs.dev/) (ابزار بیلد بسیار سریع)
- [Tailwind CSS](https://tailwindcss.com/) (استایل‌دهی سریع و منعطف)
- [Lucide Icons](https://lucide.dev/) (آیکون‌های استاندارد و زیبا)

## 💻 نحوه استفاده

1. **استفاده از نسخه وب:**
   وارد کردن آدرس `unischedule-1.ai.studio` درون مرورگر خود. (به دلیل تحریم‌ها، برای استفاده از این وب‌سایت حتماً VPN خود را روشن کنید).

2. **نسخه پکیج نصبی برای ویندوز (به زودی):**
   همزمان با توسعه نسخه وب، در حال تبدیل سورس‌کدها به پکیج نصبی ویندوز به کمک فریم‌ورک Electron.js هستیم. به زودی فایل‌های `setup.exe` و نسخه پرتابل (Portable) در دسترس قرار خواهند گرفت.
